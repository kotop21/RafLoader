# 🛠 RafLoader API (v0.0.1)

Документация по использованию Lua-движка для модификации игры **Rise and Fall: Civilizations at War**.

---

## 🚀 Как создавать моды
Просто создайте `.lua` файл в папке `scripts/`. Все глобальные таблицы (`Engine`, `Core`) уже инициализированы в `core.lua` и доступны во всех модах без использования `require`.

**Пример простого мода (`scripts/test_mod.lua`):**
```lua
print("Мод успешно загружен!")

-- Отключаем инструкцию по адресу (забиваем NOP-ами)
Engine.Memory.write_nop(0x00872A30, 16)
```

## 📚 Справочник API

### 1. Engine.Memory
Методы для прямого манипулирования памятью процесса игры.

| Метод | Описание | Параметры |
| :--- | :--- | :--- |
| `write_nop` | Заменяет код на NOP-инструкции (`0x90`) | `(address, size)` |
| `patch` | Записывает массив произвольных байт | `(address, {0xEB, 0x01})` |
| `read_int` | Читает 4-байтовое целое число (int32) | `(address)` |
| `write_int` | Записывает 4-байтовое целое число (int32) | `(address, value)` |
| `read_float` | Читает число с плавающей точкой (float) | `(address)` |
| `write_float` | Записывает число с плавающей точкой (float) | `(address, value)` |

---

### 2. Engine.Hooks
Инструменты для перехвата и подмены игровых функций. Использует MinHook через основной ASI-плагин.

#### `create(address, signature, callback)`
* **address**: HEX-адрес начала функции в памяти.
* **signature**: C-сигнатура функции (например, `void(__stdcall*)(int)`).
* **callback**: Ваша Lua-функция, которая будет вызвана вместо оригинальной.
* **Возвращает**: Указатель на оригинальную функцию (используйте для вызова оригинала внутри хука).

**Пример использования:**
```lua
local original_lobby = nil

-- Перехватываем функцию входа в лобби
original_lobby = Engine.Hooks.create(0x924350, "int(__cdecl*)(void)", function()
    print("Вход в лобби зафиксирован!")
    return original_lobby() -- Вызываем оригинальный код игры
end)
```

## 🛠 Особенности загрузчика (ScriptsLoader)
* **Игнорирование**: Файлы, имена которых начинаются с символов `_` или `.` (например, `_utils.lua` или `.config.lua`), **не** загружаются автоматически. Используйте их для хранения настроек или библиотек.
* **Безопасность**: Загрузка каждого скрипта обернута в `pcall`. Если в одном моде произойдет критическая ошибка, это не помешает загрузке остальных модов.
* **Логирование**: Все действия лоадера (успешная загрузка или текст ошибки) автоматически выводятся в системный лог игры через `print`.
